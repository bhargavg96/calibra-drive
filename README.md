# CalibraDrive
**How Well-Calibrated Are Driving World Models?**

![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)
![Python 3.9+](https://img.shields.io/badge/python-3.9+-blue.svg)

## Overview
CalibraDrive is a benchmark for evaluating the calibration and uncertainty estimation of driving world models.

## Installation
```bash
pip install -e .
```

## Quick Start
```bash
python scripts/run_inference.py
python scripts/run_calibration.py
```

## Project Structure
- `configs/`: YAML configuration files
- `src/calibra_drive/`: Source code package
- `scripts/`: Executable scripts
- `tests/`: Unit tests
